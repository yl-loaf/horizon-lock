Best Quality Horizon Lock

This app records the raw camera stream + high-rate IMU data for the highest possible stabilization quality, while showing a live horizon-locked preview.

After recording you can download the stabilized video or the raw video + IMU log for even better offline processing (e.g. Gyroflow).

⚠ Insecure origin detected
Camera and sensors are blocked when opening the file directly (file://).

Fix: Serve it over HTTP/HTTPS. On the same machine run:
python3 -m http.server 8080
then open http://localhost:8080/horizon-lock.html

On a phone: put the file on any static host (GitHub Pages, Netlify, Vercel, ngrok, etc.) and open the HTTPS URL.

Requires a secure context (HTTPS or localhost), camera permission, and motion sensor access.
iPhone: After allowing motion access, gently tilt the phone – the Roll value should start changing. Best results on modern Android Chrome.
